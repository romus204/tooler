# tooler — учёт инструментов

Сервис для учёта личных/рабочих инструментов на Go: веб-морда + Telegram-бот
поверх одной базы SQLite.

## Модель данных

- **Категории** — с вложенностью (например, «Электроинструмент» → «Свёрла и буры»).
- **Инструмент** — тип инструмента (например, «Бур SDS-plus, Bosch»).
- **Размер** — конкретный вариант инструмента (например, «6x160мм») со своим
  количеством и местом хранения. У одного инструмента может быть сколько
  угодно размеров.
- **История** — каждое изменение количества пишется в журнал с причиной и
  источником (веб или telegram).

## Запуск

```bash
go run ./cmd/tooler
```

По умолчанию:
- база данных создаётся в `data/tooler.db`;
- веб-морда слушает `:8080` → http://localhost:8080

### Переменные окружения

| Переменная                     | Назначение                                                        | По умолчанию      |
|---------------------------------|---------------------------------------------------------------------|-------------------|
| `TOOLER_DB_PATH`                 | путь к файлу SQLite                                                  | `data/tooler.db`  |
| `TOOLER_WEB_ADDR`                 | адрес веб-сервера                                                    | `:8080`           |
| `TOOLER_WEB_USERNAME`             | логин для Basic Auth веб-морды (если задан вместе с паролем)         | —                 |
| `TOOLER_WEB_PASSWORD`             | пароль для Basic Auth                                                | —                 |
| `TOOLER_TELEGRAM_TOKEN`           | токен бота от [@BotFather](https://t.me/BotFather); без него бот не стартует | —        |
| `TOOLER_TELEGRAM_ALLOWED_IDS`     | chat ID через запятую, кому разрешено менять количество через бота   | —                 |

Пример:

```bash
export TOOLER_WEB_USERNAME=admin
export TOOLER_WEB_PASSWORD='придумайте-пароль'
export TOOLER_TELEGRAM_TOKEN='123456:ABC-your-bot-token'
export TOOLER_TELEGRAM_ALLOWED_IDS='111111111,222222222'
go run ./cmd/tooler
```

Свой chat ID можно узнать у бота командой `/myid` после первого запуска
(команды чтения открыты всем, кто пишет боту, но менять количество могут
только ID из `TOOLER_TELEGRAM_ALLOWED_IDS`).

## Сборка бинарника

```bash
go build -o bin/tooler ./cmd/tooler
./bin/tooler
```

драйвер SQLite  без cgo - можно
кросс-компилировать и переносить одним файлом вместе с директорией `data/`.

## Веб-морда

- `/tools` — список инструментов, поиск и фильтр по категории;
- `/tools/{id}` — карточка инструмента: размеры, изменение количества
  (форма «±количество»), добавление нового размера;
- `/variants/{id}/history` — журнал изменений по размеру;
- `/categories` — дерево категорий, создание/редактирование/удаление.

## Telegram-бот

- `/categories` — навигация по дереву категорий инлайн-кнопками, внутри
  категории — сразу инструменты;
- открыв инструмент — список размеров с кнопками ➖/➕ для быстрой
  корректировки количества на 1;
- `/search текст` — поиск по названию/бренду/размеру/коду;
- `/use ID количество [причина]` / `/add ID количество [причина]` —
  использовать/добавить по ID размера (ID виден в результатах поиска и
  в карточке инструмента);
- `/myid` — узнать свой chat ID, чтобы попросить администратора добавить
  его в `TOOLER_TELEGRAM_ALLOWED_IDS`.
